PDF Studio
Offline and private. Files never leave this browser.
Drag and drop PDF files anywhere in this panel, or use the file picker.

Edit text

Click text on any page to change it, or add new text.

-

Click any text to edit it. Edited text is covered with the sampled background colour and redrawn in the closest standard font (Helvetica, Times or Courier, with bold and italic) using the sampled text colour. Embedded custom fonts cannot be reused. In Add text mode, click empty space to place new text. Rotated pages and non-Latin characters are not supported.

Merge PDFs

Combine several files into one document.

    No files added. Add files, then reorder with the arrows.

    Organise pages

    Reorder, rotate and delete pages across files.

    Load one or more PDFs. Drag pages to reorder, rotate or delete them. The tree on the left shows loaded files and the current page order.

    Compress PDF

    Reduce file size for easier sharing.

    Image rebuild suits scanned documents. The result is not searchable. Lossless mode may save little.

    Split PDF

    Extract pages or ranges into separate files.

    Each range becomes one PDF. All files are bundled into a single ZIP.

    Convert PDF

    Export to Word, JPEG images or PowerPoint.

    Layout preserved places each line of text at its original position with the matched font name, size, bold, italic and colour, over a background image of the page graphics with the text removed. Fonts that are not installed on your computer are substituted by Word or PowerPoint, and embedded PDF fonts cannot be extracted. Rotated text stays in the background image. Plain text flow gives reflowable text without layout. Scanned PDFs have no text to extract. JPEG exports download as a ZIP, one file per page. DOCX and PPTX use the docx and PptxGenJS libraries, loaded on first use from lib/ or a CDN.
